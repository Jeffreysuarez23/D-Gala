BASE DE DATOS:
═════════════════════════════════════════════════════════════════════════════════════════════

c_tallas (Catálogo de Tallas)
├── id (PK)
├── nombre (varchar) - "S", "M", "L", "XL", "28", "30", ...
└── ↓ Relación a productos_variantes

c_colores (Catálogo de Colores)
├── id (PK)
├── nombre (varchar) - "Negro", "Azul", "Rojo", ...
├── codigo_hex (varchar) - "#000000", "#0000FF", "#FF0000", ...
├── estado (tinyint) - Activo/Inactivo
└── ↓ Relación a productos_variantes

productos_variantes (TABLA CLAVE - Combinaciones)
├── id (PK) - Variante ID única
├── id_producto (FK → productos)
├── id_talla (FK → c_tallas)
├── id_color (FK → c_colores)
├── precio (decimal) - Precio FINAL de esta variante
└── stock (int) - Stock independiente de esta variante

FLUJO DE DATOS (AJAX):
═════════════════════════════════════════════════════════════════════════════════════════════

1. CARGA INICIAL:
   detalles.php ──(AJAX)──> api_variantes.php?action=getVariantes&id_producto=9
                  <──(JSON)─< {variantes: [...], tallas: [...], colores: [...]}

2. SELECCIONA TALLA:
   detalles.php ──(AJAX)──> api_variantes.php?action=filtrarVariantes&id_talla=6
                  <──(JSON)─< {variantes: [...], colores_disponibles: [...]}

3. SELECCIONA COLOR:
   detalles.php ──(AJAX)──> api_variantes.php?action=filtrarVariantes&id_color=1
                  <──(JSON)─< {variantes: [...], tallas_disponibles: [...]}

4. AGREGAR VARIANTE:
   detalles.php ──(AJAX POST)──> carrito_variantes.php?action=agregarVariante
                  <─────(JSON)──< {success: true, total_items: 3}

5. VER CARRITO:
   detalles.php ──(AJAX)──> carrito_variantes.php?action=obtenerCarrito
                  <──(JSON)─< {carrito: [...], total_items: 3, total_precio: 73000.00}

EVENTOS JAVASCRIPT:
═════════════════════════════════════════════════════════════════════════════════════════════

DOMContentLoaded
    ├─> cargarVariantes()          Carga todas las variantes (AJAX)
    └─> renderTallas()              Muestra botones de tallas
    └─> renderColores()             Muestra círculos de colores

Clic en Talla
    ├─> seleccionarTalla()          Marca como activa
    ├─> filtrarVariantes()          Filtra por talla (AJAX)
    └─> renderColores()             Actualiza colores disponibles

Clic en Color
    ├─> seleccionarColor()          Marca como activo
    ├─> filtrarVariantes()          Filtra por color (AJAX)
    └─> buscarVariante()            Obtiene datos de la variante

Clic "Agregar esta variante"
    ├─> Valida cantidad
    ├─> Agrega a variantesSeleccionadas (en memoria)
    ├─> mostrarVariantesSeleccionadas()  Renderiza carrito temporal
    └─> Limpia selección

Clic "Agregar todas al carrito"
    ├─> Loop en variantesSeleccionadas
    ├─> carrito_variantes.php × N (AJAX POST múltiples)
    ├─> Actualiza contador del carrito
    └─> Vacía carrito temporal

SEGURIDAD:
═════════════════════════════════════════════════════════════════════════════════════════════

✓ htmlspecialchars()     → Previene XSS
✓ PDO prepared statements → Previene SQL injection
✓ Validación de cantidad → 1-12 unidades
✓ Validación de stock    → No permite agregar más que disponible
✓ Validación de variante → Confirma que existe antes de usar
✓ Sesiones seguras       → Manejo correcto de $_SESSION

═════════════════════════════════════════════════════════════════════════════════════════════

PUNTOS CLAVE:
═════════════════════════════════════════════════════════════════════════════════════════════

1. Cada variante es ÚNICA (Talla + Color = Variante diferente)
2. Cada variante tiene PRECIO y STOCK independiente
3. AJAX sin recargas = Mejor UX
4. Carrito TEMPORAL permite agregar múltiples antes de confirmar
5. COMPATIBLE con sistema antiguo (no rompe funcionalidad)
6. Filtrado BIDIRECCIONAL (Talla → Colores, Colores → Tallas)
7. Precio FINAL mostrado (sin cálculos del lado del cliente)
8. Stock REAL validado (no permite stock negativo)
